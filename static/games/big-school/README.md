# 合成大 · 学校（Big School）

一个「合成大西瓜」玩法的上海高中版小游戏：两颗相同的校徽撞在一起就合成上一档，一路合到最大那颗。

**双击 `index.html` 就能玩**，纯离线，不需要服务器、不需要联网、没有任何 CDN 依赖。

---

## 怎么玩

1. **选校**：进入后先在网格里点一所学校。这所学校会**直接变成这一局最大的那颗球**（通关目标）。
2. 鼠标移动 / 手指拖动瞄准，**点击（或松手）投放**。键盘也能玩：`←` `→` 移动，`空格` / `回车` 投放。
   - 鼠标拖到棋盘外面再点也没关系，球会从最近的边界落下。
   - 触摸是「先拖准、松手才投」。
3. 两颗**同档**的球只要真正接触上就合成上一档（不需要重叠多少）。
4. 两颗**最大**的球（都是你选的球王）撞在一起会双双消失，外加 300 分。
5. 球堆越过上方红色虚线并持续约 1.3 秒 → 游戏结束。合出球王即通关，可以继续刷分。
6. 最高分存在 `localStorage` 里。

界面上：右上角 `分享`、`🔊` 音效开关、`↻` 重开、`⇦` 回选校。底部那条是合成链，深色的是当前能投放的档位。

### 分享

游戏里的 `分享` 按钮（以及结算弹窗里的「分享」）会弹出一个面板：

- **系统分享** —— 调 `navigator.share`，手机上会弹出系统面板，**微信、朋友圈、QQ、B站都在里面**（没有 `navigator.share` 时这个按钮会隐藏）。
- **复制文案** —— 把成绩文案复制到剪贴板，粘到任意 App。
- **QQ 好友 / QQ 空间 / 微博** —— 打开各家网页版分享入口，带上文案。
- **B站动态** —— 复制文案并打开 B站动态发布页，粘贴即可。

需要说明的是：**微信和朋友圈没有网页分享入口**（腾讯不开放），所以网页里只能靠「系统分享」调起系统面板，或者复制文案手动粘贴。另外这是个本地 HTML、没有可分享的网址，所以分享的是**文案**而不是链接。

## 每局 11 档怎么来的

选校界面一共 14 所学校可选（四校 4 + 上海实验学校 + 八大 8 + 进才中学）。默认大小顺序：上海中学 → 华二附中 → 复旦附中 → 交大附中 → 上海实验学校 → 七宝 → 南模 → **进才** → 建平 → 控江 → 延安 → 格致 → 大同 → 复兴（**进才排在建平前面**）。

开局后**固定 11 档**：

| 情况 | 组成 | 合计 |
|---|---|---|
| 选中的是四校 | 选中的 + 随机 1 所四校 + 八大(8) + 进才 | 11 |
| 选中的不是四校 | 选中的 + 随机 1 所四校 + 八大(去掉选中的) + 进才 + **上海实验学校** | 11 |
| 选中的是上海实验学校 | 上实 + 随机 1 所四校 + 八大(8) + 进才 | 11 |

也就是：**次大球永远是随机抽的一所四校**（选中的是四校就换一所），其余四校不出现；名额不够 11 档时用上海实验学校补，插在四校后面（它比八大更靠前）。

> 原先那个「硬核模式 17 所」的开关已经删掉了 —— 它和「固定 11 档」冲突。曹杨二中、松江二中、奉贤中学、位育中学的校徽也一并移除了。

## 校徽来源

脚本从**百度百科移动版**（`wapbaike.baidu.com`）词条的「校徽 / 校标」段落抓原始图。华二附中、交大附中的横版组合图改用了百度图片搜索里的方形版本；进才中学用的是学校官网（jincai.sh.cn）的校标；大同中学用的是上海大同中学（1912）圆徽；上海实验学校用的是百度图片里的绿色校标。抓到后统一做去白边、补正方形、缩放到 256×256。

校徽是各校的商标/标识，这里仅作个人娱乐用途。

## 技术说明

### 物理（`physics.js`）

- 顺序冲量求解器 + 位置修正 + 切向摩擦 + 转动惯量，固定步长 1/120 s，每步 7 次迭代；粗筛用扫描线（sweep & prune），150 颗球时单步约 0.26 ms。
- **摩擦**：球球摩擦 0.72、墙面摩擦 0.92，另加「滚动阻力」——贴地的球每步额外衰减水平速度和自转，所以球落地后基本不滑（实测初速 320 px/s 的球 2 秒内只走 40px 就停住）。
- **挤压（软接触）**：碰撞**永远是刚性的**（半径就是 `r`），挤压只是渲染层的事——把球心朝接触点挪 `r*sq`、再沿法线压扁 `(1-sq)`，压扁后的表面正好落在接触点上，既不悬空也不穿模。
  这一点很关键：早期版本用「缩小的碰撞半径」来表达挤压，结果形成正反馈——球一被压扁就悬空，掉下来砸得更狠，越砸越扁。把几何和挤压解耦之后才稳定。
- **合成判定**：两个同类球**只要真正接触上**就合成（`d ≤ r_a + r_b`，容差 0.05px）。接触记录与合成结算在同一步内完成，避免高速撞击时漏判。

### 渲染

- 每档球预渲染成离屏 canvas 精灵图（2 倍超采样），主循环只做 `drawImage` + 旋转 + 挤压变换。
- 音效是 WebAudio 现场合成的，没有任何音频素材。
- 全部本地相对路径，`file://` 直接打开即可；没有用 ES module（`file://` 下会被 CORS 拦），脚本都是传统 `<script>`。

## 测试

```powershell
node tests/physics.test.mjs
node tests/dom.test.mjs
```

`physics.test.mjs` 覆盖：尺寸表校验、地面摩擦（球不滑）、挤压（撞击压扁 / 静置回弹 / 压扁后仍贴地）、接触合成（贴着就合 / 不同档永不合 / 落下来也合）、极端堆叠下的数值稳定性与边界、单球静止、球堆不下陷、11 级合成链逐级验证、以及随机机器人和「会瞄准」机器人两种玩法模拟。

`dom.test.mjs` 用一套最小 DOM 桩把 `index.html + physics.js + game.js` 真跑一遍，覆盖：元素 id 完整性、14 所可选、**四种选校情况下的 11 档组成**（含「进才排在建平前面」）、半径单调、投球与合成计分、localStorage、拖出边界点击仍在边界落球、触摸先瞄准后松手、**分享面板（六个入口 / 打开时暂停游戏 / 关闭后恢复）**、游戏结束弹窗（且弹窗上的点击不投球）、重开与返回。

两个测试当前都是 `ALL PASS`。
