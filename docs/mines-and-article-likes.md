# 扫雷与文章点赞

## 本次功能

- 小游戏列表新增独立入口 `/games/mines/`，样式延续俄罗斯方块。
- 初级 9×9 / 10 雷、中级 16×16 / 40 雷、高级 30×16 / 99 雷、专家 30×24 / 180 雷。
- 自定义宽度 5–40、高度 5–30，雷数 1–300 且不超过格子总数减 9。修改难度与参数后点击“新一局”应用；当前棋盘名称单独显示。
- 全部为联网排位，不再提供休闲模式。每个难度独立总榜，前 50 名。同一浏览器在每个榜仅展示最快成绩。自定义按完全相同的宽、高、雷数分别排名；榜单选择自定义后按设置栏参数查询，修改参数后点击榜单刷新。
- 首次翻开及周围八格保证安全，连片空白自动展开。支持右键插旗、手机插旗开关和键盘操作；大棋盘可横向滚动。
- 双击已翻开的数字，当相邻旗数等于数字时，翻开其余未标记的相邻格；旗子位置标错仍会踩雷。手机可连续点两次数字，键盘可在数字格按 Enter 或空格。后端独立校验旗子与动作，一次展开作为同一次状态更新，错误请求不会部分改变棋盘。
- 通关后可输入昵称提交；失败不能入榜。首击即开始，排位按服务器时间计算，包含网络等待及离开页面的时间，无暂停。两小时内提交有效；同时间按提交时间再按对局 ID 排序。
- 文章正文后新增点赞与取消点赞，独立于评论，文章可通过 `likes: false` 隐藏。沿用评论 API 地址；关闭单篇评论不影响文章点赞。

## 实现与限制

Worker 保存排位棋盘，只把已经揭开的数字返回给浏览器。后端判断踩雷或胜利、核算用时，忽略客户端提交的分数或用时。对局绑定匿名浏览器标识，更新采用版本条件避免并发覆盖，成绩提交幂等。断网后点击“重新同步对局”，保留后端进度；首击请求可用同一对局编号重试。刷新整个页面不会恢复当前对局。

排名不是账号系统，清理存储或换设备会被视为新玩家。隐藏雷位无法阻止自动解题脚本；此榜单适合娱乐，不用于有奖竞赛。不同棋盘的运气、网络延迟也会影响成绩。文章点赞沿用评论的路径合法性校验，不验证路径对应的文章是否实际存在；接口不会生成文章页面。

每个 IP 每十分钟最多开始 40 个排位局、提交 30 次成绩、各执行 3000 次翻格、双击展开及同步请求；文章点赞最多 100 次。每个翻格涉及 D1 读写，正式上线后关注 Worker / D1 用量。过期对局在开启新排位局时清理，已提交成绩独立保留。排行榜目前没有后台删除入口。

## 上线顺序

先合并或取得本次代码。在项目根目录执行（沿用现有 DB、域名、管理及散列密钥）：

```powershell
npx.cmd wrangler d1 migrations apply catrix-comments --remote --config wrangler.comments.toml
npx.cmd wrangler deploy --config wrangler.comments.toml
```

新增迁移 `0004_mines_article_likes.sql`，只添加表及索引。已有 0001–0003 也需应用。随后通过现有 GitHub Pages 流程发布前端。现有 Worker 域名须覆盖 `/community/*`。
