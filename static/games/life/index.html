经典四条规则 (B3/S23)：

1. 人口过少：任何存活的细胞，若周围活细胞邻居少于 2 个，在下一代便死亡。

2. 稳定繁衍：任何存活的细胞，若周围有 2 或 3 个活细胞邻居，能继续存活到下一代。

3. 人口过剩：任何存活的细胞，若周围活细胞多于 3 个，在下一代便因拥挤而死亡。

4. 生命诞生：任何死亡的格子，若周围恰好有 3 个活细胞邻居，将在下一代诞生出新细胞。
