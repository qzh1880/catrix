# 俄罗斯方块 · 方块之间

Catrix 的纯前端小游戏，主入口是网站 `/games/` 中的嵌入页面，也可打开 `/games/tetris/` 单独游玩。所有资源均位于本目录，无外部字体、图片、CDN、账号或后台依赖。直接打开 `index.html` 也可以玩。

## 操作

- 左右方向键移动，上方向键 / X 顺时针旋转，Z 逆时针旋转。
- 下方向键加速下落，空格直接落到底，C 暂存或交换。
- P / Esc 暂停或继续；切换窗口、标签页或将嵌入游戏完全滚出视野时自动暂停。
- 手机使用下方按钮，长按左右和下落按钮可连续操作。
- 进行中点击“重新开始”会先暂停提示，再次点击才重置本局。

## 规则

棋盘 10 列 × 20 行，七种方块按七袋随机方式发放。每消除十行升一级并加快下落，最快每 80ms 自动下落一格。消除 1、2、3、4 行依次得 100、300、500、800 × 消除前等级分；软降每格 1 分，硬降每格 2 分。落地有 450ms 调整时间，移动和旋转最多重置 15 次落锁计时。

使用简化墙踢，不包含完整 SRS、T-spin、连击或竞赛规则。下一块预览显示三个，暂存每次落定后可再用一次。最高分使用浏览器 `localStorage`；存储不可用时仅保留当前页面内的最高分。

## 维护与测试

- `engine.js`：纯规则逻辑，可在浏览器和 Node 中运行。
- `game.js`：Canvas 绘图、输入、暂停和最高分存储。
- `style.css`：响应式布局，保留页面缩放。
- `index.html`：界面、按钮及操作说明。
- `tests/engine.test.mjs`：规则测试，包括碰撞、旋转、消行、落锁、暂存和随机玩法模拟。

在项目根目录执行：

```sh
node --test static/games/tetris/tests/engine.test.mjs
hugo
```

大厅模板为 `layouts/_default/games.html`，通过 `relURL` 兼容 GitHub Pages 子路径。`assets/js/games-embed.js` 只接收同源 iframe 发出的高度消息，并在游戏滚出视野时通知暂停。棋盘属于视觉游戏，屏幕阅读器可读取成绩和提示，但不提供非视觉棋盘替代玩法。
