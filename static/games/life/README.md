# 生命游戏（Conway's Game of Life）

`catrix.net/games/life` —— 游乐场第 4 个游戏。纯前端、零依赖、不联网。

## 能做什么

- **视图大小**：小 40×30 / 中 64×48 / 大 96×72 / 特大 128×96，格子边长按屏幕宽度自动算，棋盘比屏幕宽时可以横向滑动。
- **速度**：慢 4 代/秒 / 中 10 / 快 20 / 极快 40。切到后台会自动暂停。
- **边界**：环面（上下左右相接，滑翔机绕回来）或死边界。
- **图案**：12 份预设，点一下变成图章，再点棋盘落子；也可以用画笔逐格画、橡皮擦。
- **快捷键**：空格 开始/暂停 · → 或 N 单步 · C 清空 · R 随机 · Esc 回到画笔。
- 代 / 存活 / 占比三个数字实时更新；设置（视图、速度、边界）记在 localStorage。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式（与 mines / tetris 同一套游乐场风格） |
| `engine.mjs` | 纯逻辑：网格、`step()`、预设图案、落子、边界处理。不碰 DOM |
| `game.mjs` | 界面层：画布渲染、设置面板、图案调色板、鼠标/触摸、快捷键 |
| `tests/engine.test.mjs` | 引擎与图案数据的测试 |

## 测试

```bash
node --test static/games/life/tests/            # 或者在仓库根目录：npm test 之类都行
node static/games/life/tests/engine.test.mjs    # 直接跑单文件也可以
```

测试会校验每份图案的细胞数、静物不变、闪烁灯/蟾蜍/信标周期 2、脉冲星周期 3、十五周期振荡器周期 15、
滑翔机每 4 代斜走一格、顽固者第 130 代灭绝、长寿图案 100 代还在折腾、滑翔机枪持续增产，
以及边界（环面 / 死边界）、随机填充、落子裁剪、单格取反、缩略图裁剪等行为。

## 加东西

- **加图案**：往 `engine.mjs` 的 `PATTERNS` 里加一条 `{ name, en, note, ascii }`，`O` 是活细胞。
  顺手在 `tests/engine.test.mjs` 的细胞数表里补一行，测试会顺带验证它。
- **加视图 / 速度**：改 `engine.mjs` 顶部的 `VIEWS` / `SPEEDS`，界面按钮是照着这两个数组生成的，不用改 HTML。
- **改配色**：`style.css` 顶部四个变量；画布上的颜色在 `game.mjs` 的 `COLORS` 里（改的时候两边保持一致）。

## 规则

标准 B3/S23：活细胞有 2 或 3 个活邻居则存活，死细胞恰好有 3 个活邻居则诞生，其余情况死亡。
这里没有做任何"防结壳"的改动——它就是个正经的康威生命游戏，跑久了该结壳就结壳，
想看永不结壳的版本见首页背景那套 `static/js/life-bg.js`。
